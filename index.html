About me

I am a second-year B.Tech computer engineering student at Oduduwa University in Nigeria, and I am looking for an internship in web development. I like turning a plain idea into a page that loads quickly and is easy to read on any screen.

I write my own HTML and CSS instead of using page builders, because it teaches me exactly how the web works. I care about semantic structure, responsive layouts and accessibility, so that everyone can use what I build.

Outside of coding, I enjoy solving puzzles and helping classmates debug their projects.
